# Colour grading LUTs (3D, .cube, applied in display space by the post pass)

| File | Origin | Notes |
|---|---|---|
| `Anime Shinkai / Ghibli / Pastel / Punchy.cube` | generated by `tools/gen_anime_luts.py` (original work, CC0) | tuned for toon rendering: saturated blue/cyan sky, tinted lifted shadows, warm highlights |
| `Bourbon 64`, `Chemical 168`, `Clayton 33`, `Cubicle 99`, `Remy 24` (`.CUBE`) | `examples/luts/` of [mrdoob/three.js](https://github.com/mrdoob/three.js) (repository: MIT) | Photoshop "Export Color Lookup" files whose headers say *Copyright 2017 RocketStock*. The three.js repo ships them in its MIT-licensed examples, but the files carry their own copyright line: check that you may redistribute them before shipping them in a product (`tools/fetch_assets.sh` can re-download them, so they may simply be removed). All are film / photo looks (warm, green-teal, B&W, cool, faded), not anime-specific. |
| `NeutralLUT.png`, `NightLUT.png`, `B&WLUT.png`, `Presetpro-Cinematic.3dl` | same three.js folder | `NeutralLUT.png` is an identity (loader test). `B&WLUT.png` is a hard 1-bit threshold (use a low strength). `NightLUT.png` is a heavy blue night tint. `Presetpro-Cinematic.3dl` is a mild teal/violet grade; its header says *Copyright 2018 presetpro.com and Tim Martin*, so treat it like the RocketStock files (check redistribution rights). |

Supported: `.cube`, `.3dl` (blue index fastest, like three.js `LUT3dlLoader`), and horizontal or vertical strip `.png` (like `LUTImageLoader`).

The sandbox lists every `.cube`/`.3dl`/`.png` in this folder (`Post-processing -> Colour grade`), or use `--lut "Anime Shinkai"|none|path.cube --lut-strength 0..1`.
