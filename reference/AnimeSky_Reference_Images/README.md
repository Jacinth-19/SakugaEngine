# AnimeSky visual reference index

The numbered directories organize art-direction references separately from runtime assets. They are **link indices**, not a bundled image pack: the image links supplied for this request are external and may expire, were not accessible to the build environment, and no redistribution rights have been established. A clone works without downloading them; none is loaded by the engine. Add images only with permission and retain source, creator, license, and date in the relevant directory.

01–06 are reserved for style and sky/cloud references. 07 contains the requested post-processing reference taxonomy and a source index. The profile names in the engine are original descriptive labels, not replicas or official profiles of any game. Reference material guides art direction; effects are rendered by Vulkan shaders, not baked into these images.

Implementation and limitations: [Post-processing pipeline](../../docs/POST_PROCESSING.md).

For original CC0 technical diagrams (not art-style references), see [Technical Reference Charts](../Technical_Reference_Charts/README.md).
